# Dynamic OData URL Generator

## Description
This project is a chatbot-based solution that dynamically generates OData URLs based on user queries. It leverages Google's Gemini API to understand the type of question being asked and formulates the corresponding URL to fetch relevant data from an SAP system. This enables users to seamlessly interact with SAP data through natural language.

## Tech Stack
- **Streamlit**: Front-end web application framework
- **Streamlit-navigation-bar**: For enhanced navigation experience
- **Google Generative AI (Gemini API)**: For understanding and classifying user queries
- **Streamlit-AgGrid**: For displaying tabular SAP data interactively
- **Plotly Express**: For visualizing extracted data

## Features
- Chatbot interface to handle user queries.
- Dynamic OData URL generation based on query type.
- Integration with SAP for real-time data extraction.
- Interactive table views using Streamlit AgGrid.
- Visual analytics powered by Plotly Express.
